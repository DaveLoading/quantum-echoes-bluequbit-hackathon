Quantum Echoes · David

About 50 seconds. Second finding, on G4. As the pruning threshold shrinks, each qubit’s value drifts steadily in one direction; here’s qubit 10. So we borrowed the idea behind zero-noise extrapolation, with truncation playing the role of noise: run two thresholds, draw the straight line, read it at zero. That took G4 from 700 to 800. Later we got a real run at 3e-5 on this qubit, and it landed right where the line said zero was, at minus 0.053. So the drift is real and it keeps going, which is the gap between us and 900.
