Quantum Echoes · David

About 45 seconds. Here’s how the work was split. I told both Claude sessions what to run and what to write: which problems and settings to run, which retries to push, and the handoffs, records and write-ups. I also set the goals and the rules: ask me before any run over $2, and only upload a problem when it should clear 70% of its points. Fable, one Claude session, did the strategy: it chose what to run by writing lines into a task file, and from Saturday evening on it made the uploads; the captain made the first five. The captain, Claude Code in my terminal, held the API token and ran a scheduler that kept BlueQubit’s 5 job slots busy all night, collected results, and built and checked every file. Every call went through one toolkit that checks prices, keeps a spend ledger and handles qubit order. The idea came from Javier Mancilla’s city of agents that code quantum computing: I wanted to see what a small crew of agents could do on a real quantum estimation problem. The night before, four specialist agents rehearsed the whole pipeline on practice circuits.
