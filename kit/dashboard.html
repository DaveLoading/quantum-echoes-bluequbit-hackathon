Paid run run

Runs a circuit on BlueQubit through the kit. The server gets the cost estimate first; nothing is submitted until you confirm in the panel below. Refused while any other run or collect is active.

Options (chi, th, level, wcut)

Collect collect

Picks up results of jobs left running (submitted with --no-wait) and builds their CSVs. Uses the job slot, so it is refused while a run or another collect is active.

Log an upload

After you upload a CSV on the website yourself, record it here. This adds one row to the table in work/submissions.md. The dashboard never uploads anything.

Free commands

These never submit jobs. estimate and info make free calls to BlueQubit in live mode. Output shows in the console at the bottom.
